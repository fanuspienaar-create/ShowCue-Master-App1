# ShowCue

Responsive, touch-first ShowCue PWA starter.

## Included
- Home dashboard based on the approved ShowCue artwork
- Setlist, Songs, Cue Pads, Media, TV Display, Playlist, Settings, Backup and Help
- Touch-first pointer controls for iPhone/iPad/Android and desktop mouse/touch
- PWA manifest and icons for home-screen installation
- Offline service worker
- Portable JSON backup
- GitHub Pages compatible static deployment

## Deploy
Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the repository's Pages settings.

## App icon
`assets/icon-*.png` contains common PWA/iOS/Android sizes.
`assets/apple-touch-icon.png` is the iOS home-screen icon.
